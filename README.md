# HR-Analytics-Dashboard-
Interactive HR Analytics Dashboard built using Power BI.
HR Analytics Dashboard

This project is an interactive HR Analytics Dashboard developed using Power BI to analyze employee data and workforce performance. The dashboard provides detailed insights into employee attrition, salary analysis, department performance, overtime status, education qualification, gender distribution, and employee demographics.

The dashboard was built using Power BI visualizations, DAX measures, Power Query, KPI Cards, Slicers, and Map Charts to create an interactive and visually appealing reporting system. It helps HR teams monitor workforce trends, improve employee retention strategies, and support data-driven decision-making.

Key Features:
• Total Employees, Employees Left, Salary, and Attrition Rate KPI Cards
• Department-wise Employee Attrition Analysis
• Gender-wise Employee Distribution
• Year-wise Employee Attrition Trend
• Salary Analysis by Department
• Education Qualification Analysis
• Age Group and Marital Status Analysis
• City and Experience Level Analysis using Map Visualization
• Interactive Filters and Slicers

Tools & Technologies Used:
• Power BI
• Power Query
• DAX
• Data Modeling
• KPI Cards
• Slicers
• Map Visualizations

Business Insights:
• Identified departments with higher attrition rates
• Analyzed employee salary distribution across departments
• Compared overtime and normal work employee counts
• Evaluated employee demographics and experience levels
• Improved HR reporting through interactive dashboards

This project demonstrates skills in data cleaning, data modeling, data visualization, dashboard design, and business analysis using Power BI.
